Ton atelier FF7 NES

  1. Ouvre ff7_v22_base.nes depuis le pack.
  2. Recherche une phrase visible pendant ta partie. Les catégories regroupent les textes reconnus ; les lieux ne sont pas encore indexés.
  3. Modifie le texte. La jauge mesure la place disponible en octets. La police utilise un caractère de 8 pixels pour les dialogues.
  4. Enregistre un projet .ff7fr pour conserver tes corrections et la ROM de départ.
  5. Exporter ROM + IPS produit un ZIP avec la nouvelle ROM, le patch, les empreintes SHA-256 et le bilan. Le patch s’applique uniquement à la ROM que tu as chargée.

Le bouton Extraire les textes produit un catalogue JSON éditable. Importer les textes recharge un catalogue de la même ROM et vérifie toutes ses modifications.

Limites de la v0.1 : insertion dans la place existante, sans déplacement ni mise à jour des pointeurs. Cinq entrées restent protégées, dont « Continuer » qui partage des tiles avec le titre. 45 références non reconnues sont exclues. L’aperçu ne remplace pas un test dans FCEUX.

Un brouillon est conservé dans ce navigateur si le stockage local est disponible. Enregistre régulièrement le fichier projet pour retrouver ton travail sur un autre ordinateur.

Raccourci : Ctrl+S pour enregistrer le projet. Les données restent sur ton ordinateur.
